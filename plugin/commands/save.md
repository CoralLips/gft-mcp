把本场对话里的新判断存回 GFT 思维脉络。

步骤：
1. 确认本场链接的图（本场读/喂过哪张就是哪张）。没链接过 → 先按 /gft:link 的流程选图。
2. 调 `read_thinking_map`（project=图名, for_update=true）拿到：旧图别名（n1/n2…）+ 抽取规则 + 各线水位。
3. 按返回里的规则抽取——**只抽用户真说了的新判断**，你自己的分析除非用户明确接住了不上图；对照水位里你自己那条线（agent_id 匹配的），只抽那之后的对话；图上已有的判断不重复产。
4. 调 `submit_map_update`：
   - tags = 抽出的 `<node/>` `<edge/>` 标签（没有新东西传 `<noop/>`）
   - cursor = 本次抽到哪（日期 + 话题 + 位置，人话）
   - agent_id = 当前工作目录名（如 `git-for-thought`）——跨重启稳定，水位按线分记
5. 把返回的知情回执原样告诉用户（加了什么、被规则挡了什么）。

用户平时说「存一下」「记到脉络里」等自然语言，也执行本流程。
