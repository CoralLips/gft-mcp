description: GFT 登录/修复——一条命令发起网页授权，浏览器点一下完成
---

检查 GFT 白盒上下文的凭证，失效则直接发起网页授权登录。

> 注：正常情况下本命令由 plugin 的 UserPromptSubmit hook 程序化抢答（直接拉起浏览器授权），
> 你不会读到这段。你在执行 = hook 未生效——按下面步骤 AI 兜底即可。

步骤：
1. server 一律用 `npx -y gft-mcp`（无需找本地路径；本地开发仓另说）。
2. Bash 快速探测：`npx -y gft-mcp --check --list`。
   - **成功** → 告诉用户「凭证正常」，顺带给出脉络名单，结束。
   - **失败（登录失效）** → 直接发起网页授权（非交互，AI 可执行）：
     ```
     npx -y gft-mcp --login-web
     ```
     用 Bash 前台跑，timeout 设 200000ms。它会自动打开浏览器到 GFT 授权页；
     同时告诉用户：「浏览器已打开 GFT 授权页，点一下『授权接入』即可（若没弹出，手动访问输出里的 URL）」。
3. 命令输出「✅ 授权成功」后，再跑一次 `--check --list` 复验，把脉络名单报给用户。
4. 超时或失败 → 报错误原文，兜底方案：让用户开**独立终端**跑 `npx -y gft-mcp --login`（交互输邮箱密码；⚠ 不能用 `!` 前缀，接不了交互输入）。

注意：绝不索要或让用户在对话里输入密码。
