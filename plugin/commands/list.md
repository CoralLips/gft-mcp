列出用户的 GFT 思维脉络。

> 注：正常情况下本命令由 plugin 的 UserPromptSubmit hook 程序化抢答（零模型秒回），
> 你不会读到这段。你在执行 = hook 未生效（环境不支持或安装不全）——按下面步骤 AI 兜底即可。

步骤：
1. 调 MCP 工具 `list_thinking_maps`（gft server）；没有该工具就跑 `npx -y gft-mcp --check --list`。
2. 原样呈现返回的列表（已含图名、条数、各线新鲜度）。
3. 末尾补一行本场链接状态：本场对话已读/喂过哪张图就是已链接（如「本场已链接：X」）；都没有则「本场未链接——用 /gft:link 图名 或直接说要用哪张」。
4. 不要顺手读任何一张图的全文——这一步只出名单，省 token。

若工具报凭证过期：走 /gft:login 流程（跑 `--login-web` 网页授权）。
