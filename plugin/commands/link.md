把本场对话链接到一张 GFT 思维脉络：$ARGUMENTS

步骤：
1. 有图名参数 → 调 `read_thinking_map`（project=图名，模糊匹配）。
   没给参数 → 先调 `list_thinking_maps` 列出，请用户挑（回序号或名字即可），再读。
2. 读到的图就是本场的「白盒上下文」——之后回答用户时可引用其中判断（**逐字用原标题**）。
3. 报一句确认：「已链接『图名』（N 条判断，M 条还悬着）。之后说『存一下』即可把本场新判断存回这条线。」
4. 链接关系记在本场对话里即可，无需任何持久化——session 结束线自然消。

规则：一场对话同一时刻只链接一张图；换图 = 再跑一次本命令。语境不明时列候选让用户挑，不许赌"最近更新的那张"。
